## ✨ Features

**AI2Word** is a lightweight online tool designed to convert Markdown content (especially those generated by AI) into formatted Microsoft Word documents (`.docx`).

*   **📊 Mermaid to Image**: Automatically renders Mermaid code blocks (Flowcharts, Sequence diagrams, Gantt charts) into high-quality images within the Word doc. No more manual screenshots!
*   **Vx LaTeX Support**: Converts LaTeX math equations directly into native Microsoft Word equations (fully editable and lossless).
*   **👀 Real-time Preview**: WYSIWYG editor to check your document before exporting.
*   **⚡ Zero Setup**: No need to install Pandoc, Node.js, or Python. Works directly in your browser.

## 🇨🇳 中文介绍

### 为什么开发这个工具？(The Pain Point)

随着 **DeepSeek**、**ChatGPT** 等 AI 工具的普及，我们经常用它们来生成技术文档、研报或论文。AI 生成的内容往往包含大量的：
1.  **Mermaid 流程图/时序图**
2.  **复杂的 LaTeX 数学公式**

当你试图将这些 Markdown 内容直接复制到 Word 时，通常会遇到：
*   ❌ Mermaid 代码变成了一堆乱码文本，**必须手动截图**粘贴。
*   ❌ 数学公式无法识别，**格式错乱**。
*   ❌ 排版丢失，调整格式耗时耗力。

**AI2Word (ai2word.online)** 就是为了解决这个问题而生的。

### 核心功能

#### 1. Mermaid 图表自动转图片 🖼️
这是最核心的功能。工具会自动扫描 Markdown 中的 Mermaid 代码块，在导出时将其**自动渲染为高清图片**并插入 Word 文档。
*   支持流程图 (Flowchart)
*   支持时序图 (Sequence Diagram)
*   支持甘特图、类图等
*   **无需安装任何插件，无需手动截图。**

#### 2. LaTeX 公式无损转换 ➗
完美支持数学公式转换。它会将 Markdown 中的 `$E=mc^2$` 转换为 **Word 原生公式格式**。
*   导出后在 Word 中可以直接点击编辑。
*   无论是行内公式还是块级公式，都能完美渲染。

#### 3. 实时预览与极简体验 👁️
*   左侧粘贴代码，右侧实时预览 Word 渲染效果。
*   **完全免费**，无需注册，无需下载几百兆的软件（如 Pandoc）。
*   打开网页即用，用完即走。
